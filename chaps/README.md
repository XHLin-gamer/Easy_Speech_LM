## Asset layout

Keep chapter Markdown files directly in `chaps/` so their links stay stable.

```text
chaps/
  chap1_intro.md
  chap2_tokenizer.md
  assets/
    chap1_intro/
      images/
      sources/
    chap2_tokenizer/
      images/
      sources/
    shared/
      images/
      characters/
  audio/
  legacy/
```

Use relative paths with forward slashes in Markdown and HTML. File new chapter
figures under `assets/<markdown-stem>/images/` and editable Excalidraw originals
under `assets/<markdown-stem>/sources/`. Reuse shared images rather than copying
them. Legacy documents use `../assets/`. Audio samples remain in `audio/`.

`assets/chap2_tokenizer/images/8bit.jpg` is a documentation copy of the figure
generated by `src/chap3/color.ipynb`; refresh it when regenerating that figure.
